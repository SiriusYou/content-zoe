# Fallback, escalation, and next action

## Why handoff context should include a route

A handoff note is stronger when it tells the receiving user where to go next. If the output does not fit the situation, if evidence is missing, if timing has changed, or if ownership is unclear, the user needs a way to route the question.

The article may connect fallback and escalation to handoff context. A fallback contact can help when the output cannot be used as expected. An escalation route can help when the receiving user cannot resolve a concern locally.

## Next-action categories the article may discuss

- use within the reviewed boundary;
- seek clarification;
- add missing context;
- document a concern;
- use an alternate path;
- contact the owner group;
- escalate unresolved questions;
- trigger review;
- narrow reliance on the output;
- pause or retire the output for a particular use.

These are governance routing categories, not clinical instructions or legal determinations. They should not be described as proof of safety, compliance, effectiveness, fairness, or maturity.

## Boundary

Fallback planning can make handoff more actionable, but it does not prove resilience or continuity. Escalation can make unresolved questions visible, but it does not prove that every local obligation has been satisfied.
