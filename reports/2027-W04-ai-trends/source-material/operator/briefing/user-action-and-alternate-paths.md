# User action and alternate paths

## Why the user needs a practical route

A healthcare AI output may not fit the situation in front of the user. The output may be incomplete, stale, hard to interpret, based on missing context, or inconsistent with the user's professional judgment. If the only visible option is to accept the output or work around it informally, governance loses useful signal.

A disagreement path should show what a user can do next. The next action might be to document disagreement, use an alternate workflow, request review, escalate the concern, or add information that changes the interpretation.

## Alternate action categories the article may discuss

- document disagreement;
- choose a non-AI path;
- seek human review;
- add missing context;
- escalate to an owner group;
- request workflow review;
- flag a monitoring concern;
- pause reliance on the output for a narrow use;
- reopen governance review.

These are governance routing categories, not universal clinical instructions. The article should not imply that every workflow has the same alternate path or that any local action is legally required by the source basis.

## Important boundary

Do not present challenge or override as inherently good or inherently unsafe. The source-bounded claim is narrower: the route for disagreement should be visible enough that concerns can be documented, reviewed, and escalated when appropriate.
